# 0003: STEM fixes F1 to F10

Status: decided under Amish's standing instruction of 2026-10-23 (STANDARDS section 20, fix rule); each keeps the working principle (pre-scored FR polypropylene panels, tool-free clip-lock joints, printed cues, magnetic flaps at transitions) and Amish can reverse any of them. Fixes that would change the pitch, scope or a user-facing figure went to Amish instead (D2, D4, D5, D7).
